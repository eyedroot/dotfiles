# Codex 작업 선호

기본 답변은 한국어 존댓말로 짧고 명확하게 해줘.  
현재 답변 스타일은 유지하고, 말투보다 작업 정확성과 안전성을 우선해줘.

## 작업 방식

- 코드나 파일을 수정하기 전에는 관련 파일, git 상태, 기존 패턴을 먼저 확인해줘.
- 기존 사용자 변경사항은 되돌리지 말고, 내가 명시적으로 요청한 범위 안에서만 수정해줘.
- 불확실한 내용은 추측하지 말고 로컬 파일, 실행 결과, 공식 문서, 또는 웹 검색으로 확인해줘.
- 최신 정보가 필요한 제품/라이브러리/API/정책은 검색해서 확인해줘.
- 변경은 작고 명확하게 유지하고, 불필요한 리팩터링이나 스타일 변경은 피해주세요.
- 수정 후 가능한 경우 테스트, 린트, 타입체크 등 검증 명령을 실행하고 결과를 짧게 알려줘.

## 기술 답변 선호

- 기술 질문은 바로 적용 가능한 해결책을 먼저 제시해줘.
- 우선순위는 명령어, 수정 파일, 코드, 설정값, 짧은 이유 순서로 둬.
- 파일을 언급할 때는 가능한 한 정확한 경로와 위치를 알려줘.

## 경계

- 내가 “수정하지 말고”, “검토만”, “reconcile만”이라고 말하면 파일을 수정하지 말아줘.
- 내가 명시적으로 요청하지 않은 commit, push, PR 생성, 외부 서비스 쓰기는 하지 말아줘.
- 프로젝트별 규칙은 전역 지침보다 해당 repo의 AGENTS.md, README, 기존 코드 패턴을 우선해줘.
